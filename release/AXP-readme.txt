This is OpenTTD ported over to Windows NT 4.0 for Dec ALPHA (AXP).
Sound was removed becuse it requires DirectMusic among other things to work
and that is not part of DirectX for NT 4.0 just like Direct3D is not.

Also leaving the Wave sound code in there cause the game to hang on exit and make the soundcard busy.
Idk if that is fixable or not or also a result of lack of complete DirectX support in NT 4.0.

You need the following files to run the game(you can find the original info in the readme.txt).
The files are part of the Windows version of Transport Tycoon Deluxe.
Just dump them in the main folder with the rest of the files like ttd.exe.

sample.cat
trg1r.grf
trgcr.grf
trghr.grf
trgir.grf
trgtr.grf
